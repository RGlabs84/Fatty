Fatty — Synergy Status-Effect Icons
===================================

Drop your generated PNG icons in THIS folder and rebuild the mod. They get
embedded directly into Fatty.dll (no extra files ship to players).

Expected filenames (case-insensitive, must end in these names):
  BalancedDiet.png    -> Balanced Diet   (1 Meat + 1 Veggie)
  SugarRush.png       -> Sugar Rush       (3 Sweets + 1 Drink)
  Fisherman.png       -> Fisherman's Friend (2 Fish + 1 Veggie)
  Lumberjack.png      -> Lumberjack's Feast (3 Meat + 1 Drink)

Recommended format:
  - 128 x 128 px (64 x 64 also fine), PNG with transparency
  - Centered / roughly circular so it reads at ~32 px in the buff bar

Any icon you DON'T provide is auto-replaced by a drawn procedural fallback,
so the mod always has valid icons even with this folder empty.
